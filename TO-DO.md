# Record Buddy
Ultimately create an on-matrix GUI that can be used to create digital rips of the vinyl in WAV or FLAC file formats (user specified, potentially with a "both" option) alongside a status indicator and automatic start/stop detection (start recording when needle hits record, stop recording when ~15 seconds of silence detected). Only real caveat for creating the rips is that it records the whole side of the record without a way to automatically cut between songs. I'd rather this not be algorithmic anyway as I have plenty of albums on vinyl which contain songs that flow seamlessly in between each other.
